## 📖 About The Portfolio

This repository hosts the official personal portfolio website of **Dikshant Sharma**.

Crafted with an **editorial, dark-mode luxury aesthetic**, the portfolio delivers an immersive experience presenting real production achievements, enterprise ERP architecture, and live applications.

### 🌟 Key Highlights

- **Aesthetic Depth**: High-contrast matte canvas (`#030303`) layered with ambient warm amber glows (`#ff8c59`) and subtle micro-grain textures.
- **Editorial Typography**: Pairing the literary elegance of **Instrument Serif** italic headlines with the structural precision of **DM Sans** and monospace telemetry in **JetBrains Mono**.
- **Interactive Product Chrome**: Custom realistic mockups with browser toolbars, live crypto price charts, ERP inventory audit tables, and terminal code blocks.
- **Accessibility & Motion Control**: Built-in `MOTION ON / OFF` toggle with saved user preferences in `localStorage`.
- **Zero-Dependency Lightweight Build**: Ultra-fast performance, pure native web standards with zero bloated client libraries.

## 💻 Getting Started (Local Development)

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- [npm](https://www.npmjs.com/)

### 1. Clone the repository
```bash
git clone https://github.com/Dikshant182006/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Launch local development server
```bash
npm run dev
# or
npm start
```

Your server will spin up instantly at:
👉 **`http://localhost:3000`**

*(Alternatively, you can simply double-click `index.html` to open it in any browser with zero installation!)*

## ☁️ Deployment

### One-Click Deploy to Vercel

This repository includes a production-ready `vercel.json` configuration file with clean URLs and security headers.

#### Via Vercel CLI:
```bash
npm i -g vercel
vercel
```

#### Via GitHub:
1. Push your repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: complete portfolio setup"
   git branch -M main
   git remote add origin https://github.com/Dikshant182006/portfolio.git
   git push -u origin main
   ```
2. Navigate to [vercel.com/new](https://vercel.com/new).
3. Import your `portfolio` repository and click **Deploy**. Vercel will build and host it with zero extra configuration.
